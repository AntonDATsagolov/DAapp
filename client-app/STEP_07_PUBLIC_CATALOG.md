# DAapp — шаг 7: публичные организации Шиели на карте

Добавлен отдельный каталог `public.map_places` с картографическими координатами. Он **не перезаписывает** существующую таблицу `businesses` и не зависит от входа в профиль.

## 1. Один раз установить таблицу через SQL Editor

Откройте Supabase Dashboard → **SQL Editor** нужного проекта и выполните всё содержимое:

`supabase/migrations/004_shieli_public_map_places.sql`

Миграция проверяет, что таблицы ещё нет. Если `public.map_places` уже существует, SQL остановится — прежде нужно изучить существующую схему, а не удалять данные.

## 2. Как работает безопасность

- Новые организации скрыты: `is_published=false` по умолчанию.
- Анонимные и авторизованные жители могут **только читать опубликованные** строки — благодаря RLS.
- У браузерного клиента **нет INSERT, UPDATE или DELETE** для каталога. Редактирование остаётся в SQL Editor у администратора.
- Роли из `profiles` и данные `businesses` не меняются.
- Названия и адреса показываются через `textContent`, без вставки HTML из базы.
- На карту загружается максимум 150 объектов в ограниченном районе Шиели. Фото и дополнительные документы не загружаются.

## 3. Публикация реальной организации

Сначала проверьте **название, тип, адрес и точку расположения** по достоверному источнику (лично, владельцем, проверенной картой). Не публикуйте примерные или выдуманные координаты.

При добавлении в SQL Editor запись оставляют `is_published=false` до проверки:

```sql
-- ШАБЛОН: перед запуском заменить ВСЕ значения на реальные.
insert into public.map_places
  (name, category, address, latitude, longitude, is_published)
values
  ('РЕАЛЬНОЕ НАЗВАНИЕ', 'shop', 'ПОДТВЕРЖДЁННЫЙ АДРЕС',
   44.17603, 66.74096, false);
```

**Внимание:** координаты в шаблоне — центр Шиели, НЕ место организации! Они не подходят для публикации без замены.

После проверки можно включить публикацию у выбранной строки по её UUID через SQL Editor:
```sql
update public.map_places
set is_published = true
where id = 'UUID_ПРОВЕРЕННОЙ_ЗАПИСИ';
```
Вставляйте только реально существующий UUID. Не публикуйте все строки массово.

## 4. Что увидит житель

Откройте https://antondatsagolov.github.io/DAapp/client-app/ — карту можно просматривать без регистрации. Опубликованные точки отображаются маркерами и в списке под категориями. Нажатие на карточку центрирует карту и открывает всплывающую подсказку. Категории работают локально, без дополнительных обращений к базе.

Если SQL ещё не установлен, интерфейс честно покажет «Каталог организаций ещё не создан в Supabase». Если таблица установлена, но нет опубликованных записей, отобразится «Пока нет опубликованных проверенных организаций Шиели».

## 5. Следующий шаг

Когда появятся первые реальные опубликованные точки, можно добавить заявку предпринимателя на свою организацию и её подтверждение администратором. Для этого потребуется отдельно проверить фактическую схему `businesses`, существующие RLS и права владельцев; текущая миграция их не меняет.

## Ограничения

Это первая версия каталога, а не полноценная система управления организациями. Пока нет добавления точек из `business-app`, модерации заявок, часов работы и подтверждения владельца. SQL-миграция **не выполняется автоматически** при обновлении GitHub Pages.
