# DAapp

Digital Village Ecosystem — три мобильных PWA-интерфейса с единой базой Supabase.

## Структура
- `client-app/` — жители и гости
- `business-app/` — предприниматели
- `driver-app/` — водители
- `shared/supabase.js` — общий браузерный клиент Supabase

## Запуск
Используйте локальный HTTP-сервер из корня проекта (не открывайте HTML через `file://`). Например: `python3 -m http.server 8000`. Затем откройте `http://localhost:8000/client-app/`, `/business-app/` или `/driver-app/`.

## Безопасность
В репозитории хранится только публичный Supabase publishable key. Запрещено добавлять secret/service_role ключи. Перед доступом к данным необходимо настроить Supabase Auth и RLS-политики для каждой таблицы. Публичный клиент не должен обходить RLS.

## Статус
Создана только стартовая структура и инициализация клиента Supabase. Интерфейсы, аутентификация, офлайн-кеш PWA и бизнес-логика будут добавляться поэтапно.
