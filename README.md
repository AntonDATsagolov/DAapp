# DAapp — цифровой Шиели (Шиелі)

DAapp — единая экосистема для **посёлка Шиели, Шиелийский район, Кызылординская область, Казахстан**. Три мобильных веб-интерфейса используют один проект Supabase.

**Главный адрес:** https://antondatsagolov.github.io/DAapp/

## Интерфейсы

- [Для жителей и гостей](https://antondatsagolov.github.io/DAapp/client-app/) — интерактивная карта Шиели, категории, геолокация по разрешению, переход по координатам и профиль.
- [Для предпринимателей](https://antondatsagolov.github.io/DAapp/business-app/) — подача заявки на организацию Шиели и просмотр собственных статусов; публикация только после модерации.
- [Для водителей](https://antondatsagolov.github.io/DAapp/driver-app/) — мобильный кабинет, приватная анкета водителя, проверка администратором и выход на линию. Заказы пассажиров **пока не подключены**. Для сохранения нужен [SQL 007 и настройка](driver-app/STEP_11_DRIVER.md).
- [Модерация](https://antondatsagolov.github.io/DAapp/admin-app/) — отдельная панель для проверенного администратора: очередь заявок, одобрение с проверенными координатами, отклонение и журнал решений в базе. Нужна миграция SQL 006 и ручное назначение администратора. В панели есть безопасная кнопка проверки пяти компонентов без записи в базу. [Инструкция](admin-app/STEP_09_ADMIN.md).
- `shared/supabase.js` — общий публичный клиент Supabase.
- `supabase/migrations/` — SQL для настройки базы (выполняется администратором отдельно).

## Начальная карта

При открытии карта показывает Шиели около координат **44.17603, 66.74096** (точка населённого пункта OpenStreetMap), масштаб 13. Это **ориентир населённого пункта**, а не точное местоположение пользователя. Для показа текущей геопозиции нужна кнопка «Где я?» и разрешение браузера. Список и маркеры публикуемых организаций читаются из отдельной таблицы `public.map_places` после ручного выполнения SQL-миграции 004. Если таблица ещё не создана или не содержит проверенных точек, карта остаётся доступной без них. Инструкция: [шаг 7 — публичный каталог](client-app/STEP_07_PUBLIC_CATALOG.md). Подробности: [Шаг 6 — карта](client-app/STEP_06_MAP.md).

## Вход и регистрация

Три пользовательских приложения (**жители, предприниматели и водители**) используют один Supabase Auth. По e-mail отправляется Magic Link; для нового адреса создаётся аккаунт при подтверждении письма. В **админ-панели регистрация новых аккаунтов отключена**: нужен уже существующий пользователь, заранее внесённый в `daapp_admins`.

Чтобы вход работал после перехода из письма, добавьте **все четыре** адреса приложений в Supabase Authentication → URL Configuration → Redirect URLs. В Authentication → General / Providers разрешите **Allow new users to sign up** и **Email**. Доставка письма зависит от настройки отправителя и лимитов почты; успешный HTTP-ответ без реального тестового ящика **не доказывает доставку**. Адреса настройки показаны на [странице диагностики](https://antondatsagolov.github.io/DAapp/diagnostics/).

Автоматические тесты симулируют вызов `signInWithOtp` в каждом приложении с точным URL возврата, не создавая настоящих аккаунтов и не отправляя письма. Не используйте сервисные/секретные ключи для тестирования через браузер.

## Запуск и тесты

GitHub Pages автоматически публикует обновления основной ветки `main`; localhost не требуется. Для локальной разработки: `python3 -m http.server 8000` из корня, затем `http://localhost:8000/client-app/`.

Тесты: `node --test tests/smoke.test.mjs`. Они автоматически проверяются в GitHub Actions.

## Безопасность и текущие ограничения

В репозиторий разрешено записывать только Supabase **publishable key**, никогда `sb_secret_*` или `service_role`. Доступ к таблицам должен ограничиваться RLS. Карту можно просматривать без входа, а настройки профиля требуют Supabase Auth. Полноценное управление каталогом предпринимателя, редактирование опубликованных организаций, бизнес-заказы, реальные заявки на такси и доставку, офлайн-кэш и устанавливаемые PWA ещё не реализованы. Для приёма заявок требуется ручная миграция `005_shieli_place_submissions.sql` и разрешённый redirect URL бизнес-приложения. [Шаг 8 — заявки](business-app/STEP_08_SUBMISSIONS.md).
